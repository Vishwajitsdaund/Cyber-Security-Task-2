# Task 2: Operating System Security Fundamentals

## 📌 Project Overview
This repository serves as the submission for **Task 2** of the Cyber Security Internship. The goal was to explore OS-level security, focusing on user privileges, file permissions, and system hardening on Windows and Linux.

## 📄 Contents
* **`Task_2_OS_Security_Checklist.pdf`**: A document detailing:
  * Difference between Administrator and Standard user privileges.
  * Explanation of Linux permissions (`chmod`, `chown`).
  * A comprehensive **OS Security Checklist** for hardening a system.

## 🛠️ Tools & Concepts
* **Operating Systems:** Windows 10/11 & Linux (Ubuntu concepts).
* **Commands Learned:**
  * `ls -l` (List permissions)
  * `chmod` (Change permissions)
  * `sudo` (Execute with admin privileges)
* **Security Tools:** Windows Defender Firewall, UFW (Uncomplicated Firewall).

## 🔑 Key Learnings
* **Least Privilege:** Learnt why daily tasks should never be done as a "Root" or "Administrator" user.
* **Attack Surface:** Verified that disabling unused services (like remote desktop or FTP) significantly reduces risk.
* **File Security:** Understood how Linux permission bits (Read/Write/Execute) prevent unauthorized data access.
